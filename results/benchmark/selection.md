# Label-free model selection over whole candidate pools (amendment v2)

Positive-polyp Dice (v2 metrics). Each pool holds every saved checkpoint of the listed methods on that target (all lambdas and base runs). Oracle = best candidate by target labels. Loss = Oracle Dice − picked Dice, 95% interval from the group bootstrap in analyze.py. Rank = Source-Risk's position among the validators scored for every candidate (1 = smallest loss). This is selection across methods; the main results instead fix the method and use Source-Risk only to pick the checkpoint within each trajectory. `clinicdb/clinicdb_full.md` is the v1 analysis of ClinicDB's 1,860-candidate pool, the only adapted pool with all 19 validators (ClinicDB has no empty masks, so v1 = v2 there).
