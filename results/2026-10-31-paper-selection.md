# 前景一致性选模与双指标集成（2026-10-31）

## 结论

基于原六组已训练的 U-Net 检查点，完成一次**不重新训练**的无标签选模改进。参考 [Talks 等的 CMR-NHD](https://arxiv.org/pdf/2503.00450)，只在两次预测的前景并集上计算一致性，避免大面积背景主导原先的全图概率差。参考 [Xiong 等的完整 UDA 管线研究](https://arxiv.org/pdf/2608.12035)，将源域验证选出的模型与 CMR 选出的模型按原始分辨率概率 1:1 集成。后者是该论文集成思想在本项目中两个选模指标、单一训练方法上的简化应用，并非论文的跨算法集成复现。

**A0 有稳定的探索性收益，A1 没有跨目标集一致提升。** CMR 相对同种子源域选模的三种子平均总体 Dice 差值：

| 训练增强 | CVC-ClinicDB | CVC-ColonDB | ETIS |
| --- | ---: | ---: | ---: |
| A0，CMR | +0.0521 | +0.0537 | +0.0264 |
| A0，源域＋CMR 集成 | +0.0294 | +0.0201 | +0.0161 |
| A1，CMR | +0.0013 | −0.0074 | −0.0088 |
| A1，源域＋CMR 集成 | +0.0054 | −0.0015 | +0.0033 |

三个目标集的结果在本轮设计前都已被多次查看，因此**全部只是探索性观察，不能视作独立确认**；在同一批数据上继续微调门槛、扰动强度、权重或阈值没有确认性意义。

## 固定方法

- 候选池是原始 A0/A1 × 种子 42、43、44 的各 30 个 epoch 检查点。沿用此前已探索的源域 Dice 距离最优不超过 0.02、目标选择集空预测比例不高于源域选模 +0.02 的限制，共进入 CMR 打分 20 个检查点。该门槛已受先前目标结果影响，不是前瞻设定。
- 只读取原 `target_select/images` 的 185 张无标签 CVC-ClinicDB 图像。每张图施加固定随机种子生成的高斯噪声，标准差 0.05；预测阈值 0.5。CMR-NHD 在本二分类任务等价于原预测与扰动预测前景集合的 IoU；空并集记 0，避免全空预测被奖励。每模型取逐图分数中位数，平分时优先更高源域验证 Dice。论文的实验包含其他生物医学图像任务，本实现对结肠镜图像的适用性需单独验证。
- 源域与 CMR 两个检查点按预测概率各占 0.5，在原始掩码网格上集成，统一阈值 0.5。若两种选择相同，则集成等于该单模型。
- `paper_selection_protocol.yaml` 固定规则及六份原选模文件的 SHA-256。先运行 `scripts/select_paper_cmr.py`，保存本地 `cmr_selection.json`；之后 `scripts/evaluate_paper_selection.py` 校验协议与权重哈希才读取目标测试掩码。最终文件将所用选择文件 SHA-256 记入结果。本地完整逐图输出、权重、数据仍位于 Git 忽略的 `runs/` 与 `data/`。

CMR 在六组中的选模 epoch：A0 42: 24→24；A0 43: 25→22；A0 44: 30→23；A1 42: 30→30；A1 43: 24→19；A1 44: 23→23。箭头左边是源域选择，右边是 CMR 选择。A1 种子 44 的限制条件只留下 1 个候选，任何排序指标都无法改变它。

## 配对结果与解释

下表是同一种子、同一目标集的 CMR 减源域 Dice；未改选时差值为 0。每张图均用原始分辨率掩码计算指标。

| 组合 | CVC-ClinicDB | CVC-ColonDB | ETIS |
| --- | ---: | ---: | ---: |
| A0 / 42 | 0 | 0 | 0 |
| A0 / 43 | +0.1009 | +0.0916 | +0.0254 |
| A0 / 44 | +0.0554 | +0.0696 | +0.0538 |
| A1 / 42 | 0 | 0 | 0 |
| A1 / 43 | +0.0039 | −0.0221 | −0.0265 |
| A1 / 44 | 0 | 0 | 0 |

前景限制的 CMR 在 A0 两个真正发生改选的种子上都找到更好的模型，支持原先“背景主导一致性得分”的失败分析；但 A1/43 的 CMR 选模在两个外部集退化，说明前景一致性仍不是可靠的目标 Dice 估计器。1:1 集成减少了 A1/43 的 CVC-ColonDB 损失，但未完全消除。小息肉（原始掩码面积 <2%）中，A1 的 CMR 三种子平均 Dice 在 Clinic、ColonDB、ETIS 分别为 −0.0553、−0.0275、−0.0184，不能用总体均值掩盖此风险。

本轮没有训练实验。仅运行了选模与一次完整 GPU 评估，没有进行扰动强度/权重搜索或重复低价值测试。Windows RTX 5070 执行推理；Mac 仍只用于编辑和 Git。

## 后续判断

这两篇论文提供了更合理的候选排序和降低单一选模风险的办法，但现有结果仍**不支持跨 A0/A1 和三个目标集一致提升**。后续如果要确认方法有效，应先锁定此规则并取得未参与上述诊断的独立目标集，最好带病例或视频分组信息。论文还讨论少量目标标签选模；采用它会改变本项目“完全无标签目标选模”的研究问题，需要作为单独实验提出。
